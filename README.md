# Education_Wage_Data_Visualization_Project
This repo contains the python code files and connected raw data files, a Tableau dashboard, along with an Inkscape Graphic to cover the key data insights. The CollegeScoreboard and Bureau of Labor Statistics are the sources of the data.

There is one updated Python file that was used to merge raw data file, perform EDA, and data analysis before outputting a .csv to upload into the Tableau dashboard. The Tableaus dashboard is the central deliverable for this project.

The key audience for this dashboard are US university administrators and US policy makers interested in undergraduate affordability and debt load impacts. The dashboard is intended to primarily be used as an analytical dashbaord to assist the audience in study trends within their specific geography, ownership (Public vs Private schools), and year. 

One of the main issues with handline this dataset was the lack of continuity within the dataset that was being merged to feed this dashboard. Where my analysis in the Data Modeling class was focused on tuition rates primarily, this project's focus shifted to the income of graduates 10 years after graduation. This metric made for more meaningful insights into the long term benefit of college education on incomes as compared to the US median population's income. Unfortunately this 10-year income data was not complete within the 2013-2020 timeframe this report focuses on. 

There are two code files related to a prior data analysis project. One contains the SQL analysis done using SQLite, and the other is the python portion of the analysis.

Also included are the raw data files pulled from the sources cited in the python code files.
